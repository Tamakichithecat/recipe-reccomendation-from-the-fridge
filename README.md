# recipe-reccomendation-from-the-fridge

冷蔵庫にある食材を使って、一番安上がりな料理のレシピを考えたいが、どんなレシピが最も安上がりか、足りない食材は何か、近くのどのスーパーで安くその食材が手に手に入るかを提案するiOSアプリです。

## 追加した機能（OpenAI API連携）

- 入力された食材情報・レシピ候補・店舗価格情報をもとに、OpenAI API を呼び出して「最安で実現可能なレシピ」を提案します。
- OpenAI APIの呼び出しに失敗した場合は、既存のローカルロジック（`RecipeEngine`）でフォールバック提案します。

## OpenAI APIキーの設定

以下のどちらかで `OPENAI_API_KEY` を設定してください。

1. 実行環境の環境変数に設定する
2. Appの `Info.plist` に `OPENAI_API_KEY` を追加する

未設定の場合は OpenAI 呼び出しがスキップされ、ローカルロジックで提案されます。
